# Локальный интерфейс Production Control

Браузер обращается напрямую к FastAPI. Отдельного фронтенд-сервера, прокси и чтения `.env` на фронтенде нет. Все секреты читает только бэкенд.

## Запуск

В корневом `.env` включите локальный режим:

```dotenv
ASSISTANT_LOCAL_ENABLED=true
```

Настройки модели и сертификата остаются в `.env` бэкенда. Клиентский `ASSISTANT_API_KEY` в локальном режиме не требуется для запросов с loopback-адреса и локальным Host. По умолчанию локальный режим выключен; без него проверка API-ключа сохраняется.

Из корня проекта:

```bash
docker compose up -d --wait postgres redis
poetry run alembic upgrade head
poetry run uvicorn src.main:app --reload --host 127.0.0.1 --no-proxy-headers
```

Откройте http://127.0.0.1:8000/#assistant. Бэкенд отдаёт файлы только из frontend/public. API и /health зарегистрированы раньше статических файлов и продолжают работать.

На фронтенде используется обычный fetch('/api/v1/assistant/ask') с JSON-вопросом. Ключей в HTML, JavaScript и браузерном хранилище нет. CORS не требуется, потому что страница и API имеют один origin.

Режим предназначен для локальной разработки, запускайте сервер на 127.0.0.1. Для публичного размещения нужна отдельная пользовательская авторизация. Во внешних запросах локальный флаг не отменяет проверку ключа.

## Интерфейс

Существующие разделы обзора, партий, продукции, рабочих центров и отчётов сохранены. В разделе «Ассистент» можно задать вопрос о партии по внутреннему ID, увидеть ответ и три показателя. В каждом вопросе указывайте ID: история отображается в браузере, но не передаётся модели как продолжение диалога.

Для отчётов, импорта, экспорта и фоновых операций дополнительно нужны RabbitMQ, MinIO и Celery workers; они не требуются для чтения статистики ассистентом.

Папка frontend пока исключена из Git и Docker-контекста существующими правилами. Приведённый запуск рассчитан на локальный Python-процесс.

## Поиск партий

Ассистент теперь выбирает между статистикой по ID и поиском по производственному номеру и необязательной дате. Например: «Найди партию №41 от 10 ноября 2026». При нескольких совпадениях появляются карточки и запрос уточнить дату. Кнопка «Статистика ID …» только заполняет поле вопроса; отправьте его для получения показателей. Поиск и получение статистики пока являются двумя самостоятельными запросами.
